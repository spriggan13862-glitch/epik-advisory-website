EPIK ADVISORY — LOGO KIT
========================================================
Built from your two master logos (white-bg + black-bg).
Every file is PNG. Folders are numbered by use case.

HOW TO CHOOSE:
- On a WHITE / light background  -> use a "light" file (black EPIK wordmark)
- On a BLACK / dark background   -> use a "dark" file (white EPIK wordmark)
- Over a photo or color block     -> use a file from 08-Raw-Transparent
- Browser tab / app icon          -> use 06-Favicons

NOTES
--------------------------------------------------------
- All files are PNG and drop straight into web tools, Office, Google,
  Canva, or a print shop.
- Light files = black "EPIK ADVISORY" wordmark. Dark files = white wordmark.
  The gold "K" and "Clarity. Strategy. Value." tagline are the same on both.
- For sizes larger than 2048px (billboards, large posters), ask for a
  vector (SVG) rebuild.
